## What is Zeus?

Zeus is a fast, modern SDR client for **original-protocol (Protocol 1)** and **Protocol-2** radios — Hermes, Mercury/Penelope/Metis, the full **ANAN-class** lineup (10 / 10E / 100 / 200D / G2 / 8000DLE …), and the **Hermes-Lite 2**. A .NET backend drives **WDSP** — the DSP engine the OpenHPSDR community trusts — and serves a Vite + React front end you can run as a **native desktop app** or right in your **browser**, on every major platform.

## Highlights

- 🖥️ **Truly cross-platform** — macOS, Windows, Linux, and Raspberry Pi
- 📻 **Wide radio support** — OpenHPSDR original-protocol + ANAN-class Protocol 2 + Hermes-Lite 2
- 🎚️ **Real DSP** — native WDSP via P/Invoke: PureSignal, panadapter & waterfall, full TX chain
- 🌐 **Desktop or web** — the same UI as a native app or in a browser
- 🔌 **Plugins** — audio chain, amplifier control (RF2K-S), HamClock, and more
